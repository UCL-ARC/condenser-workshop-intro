# Working on Condenser

## How to apply for a tenant

Use [this form in MyServices](https://io.uk.xurrent.com/cnQ9NDU1Mg) to describe your project and apply for a tenant. ARC projects that only require CPUs are free. For projects that would benefit from access to a GPU, we can provide GPUs on a case-by-case basis.
